快速开始 / 发起第一个请求

发起第一个请求

本指南将带你完成从注册到成功调用模型 API 的全过程。Ker API 兼容 OpenAI 接口规范，使用官方 SDK 将 base_url 替换为 Ker API 地址即可，通常只需 3 行代码改动。

前置条件

  • 已完成注册并登录 Ker API 控制台（支持手机号 / 邮箱）
  • 完成个人或企业实名认证（未认证账户可用模型与速率受限）
  • 账户有可用余额或处于试用期内

第 1 步：获取 API Key

进入「API Key 管理」页面
登录控制台后，在左侧导航选择「API Key 管理」，点击「新建 API Key」。
设置名称与规则（可选）
可为 Key 命名、设置可调用模型范围、额度上限与有效期。
复制并保存 Key
Key 仅在创建时完整展示一次，请立即保存到安全位置。
!API Key 等同于账户凭证，请勿提交到代码仓库或公开渠道。建议为不同业务创建独立 Key，便于隔离与按 Key 统计用量。

第 2 步：发起请求

将 base_url 设置为 https://api.kerapi.cn/v1，模型名使用模型广场中的完整 ID（如 deepseek-ai/DeepSeek-V3.2）。

cURL Python Node.js 
curl https://api.kerapi.cn/v1/chat/completions \
  -H "Authorization: Bearer $KER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-ai/DeepSeek-V3.2",
    "messages": [
      { "role": "user", "content": "你好，请介绍一下你自己。" }
    ]
  }'
# pip install openai
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.kerapi.cn/v1"
)

response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V3.2",
    messages=[{"role": "user", "content": "你好，请介绍一下你自己。"}]
)

print(response.choices[0].message.content)
// npm install openai
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.KER_API_KEY,
  baseURL: "https://api.kerapi.cn/v1"
});

const res = await client.chat.completions.create({
  model: "deepseek-ai/DeepSeek-V3.2",
  messages: [{ role: "user", content: "你好，请介绍一下你自己。" }]
});

console.log(res.choices[0].message.content);

第 3 步：解析响应

返回结构兼容 OpenAI 格式，正文位于 choices[0].message.content，用量信息位于 usage 字段，可用于对账：

{
  "id": "chatcmpl-9f3ab2",
  "model": "deepseek-ai/DeepSeek-V3.2",
  "choices": [{
    "message": { "role": "assistant", "content": "你好！我是 DeepSeek…" },
    "finish_reason": "stop"
  }],
  "usage": { "prompt_tokens": 12, "completion_tokens": 208 }
}
i请求失败时，错误信息集中在 error.code 与 error.message，完整错误码列表见「API 参考 → 错误码」。触发限流时请参考「速率限制与用户等级」升级说明。
